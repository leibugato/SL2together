# MVP 测试清单

## 页面

- [ ] 未配置环境 ID 时显示配置提示，页面不白屏。
- [ ] 首页统计、最近记录和快捷新建正常。
- [ ] 十种内容类型切换后显示对应补充字段。
- [ ] 名称、描述长度和 URL 校验提示正确。
- [ ] 长文本、长标题和长 URL 不横向溢出。
- [ ] 记录列表分页、类型和状态筛选正常。
- [ ] 详情页能复制设计正文和资源链接。
- [ ] 详情页能生成分享标识、复制标识并调起微信分享。
- [ ] 首页“导入分享”能用有效标识创建新草稿，无效或过期标识显示错误。
- [ ] 评估结果页在窄屏下不溢出。

## 数据闭环

- [ ] 首次进入自动创建 `users` 记录。
- [ ] 保存草稿后可再次编辑。
- [ ] 确认提交不触发评估，也不改变已有评估结果。
- [ ] 保存并评估在 `DRAFT` 状态下产生任务和评估记录。
- [ ] 评估完成后可以返回修改，修改会使旧评估过期。
- [ ] 评估完成后可以直接确认提交，提交不改变已有评估。
- [ ] 修改设计后 `contentVersion` 增加。
- [ ] 修改后旧评估显示“已过期”。
- [ ] 导入分享后不复制原用户身份、评估结果和历史记录。
- [ ] 评估结果能够标记是否可在白名单内生成 MOD。
- [ ] 可生成的设计能下载 MOD ZIP 和源码 ZIP，失败时显示原因。
- [ ] 删除后普通列表不再显示。

## 权限

- [ ] 用户只能读取自己的提交。
- [ ] 客户端不能直接写核心集合。
- [ ] 伪造 `_openid` 无效。
- [ ] 管理员集合不包含硬编码 OPENID。

## AI

- [ ] Mock Provider 能返回四档难度和完整结构。
- [ ] 规则结果包含技术依据。
- [ ] 非法模型 JSON 不写入正式评估。
- [ ] 超出范围的分数和置信度被拒绝或收敛。
- [ ] 模型超时进入可重试或失败状态。

## 发布前

- [ ] dev 和 prod 环境分离。
- [ ] AI Key 只存在云函数环境变量中。
- [ ] 所有核心集合权限为仅云函数可读写。
- [ ] 关键索引已经创建。
- [ ] 隐私说明包含第三方 AI 处理。
- [ ] 真机预览完成。
