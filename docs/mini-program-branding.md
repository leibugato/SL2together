# 小程序命名与简介

## 1. 主推荐

| 项目 | 内容 |
| --- | --- |
| 小程序名称 | SL2Together |
| 小程序简称 | SL2Together |
| 小程序简介 | 记录《杀戮尖塔 2》MOD 设计想法，按卡牌、遗物、事件、角色等类型归档，并提供 AI 实现难度评估与调整建议。 |

适用理由：

1. 不直接宣称与游戏官方有关。
2. “尖塔”具有游戏主题辨识度。
3. `SL2Together` 与项目仓库和产品定位保持一致，名称简洁且便于分享。
4. 简介同时覆盖提交、归档和 AI 评估三个核心能力。

---

## 3. 发布注意

1. 小程序名称必须具有唯一性，提交前需要在微信公众平台检查是否被占用。
2. 不要在名称或简介中使用“官方”“授权”“合作”等可能让用户误认为与游戏厂商有关联的表述。
3. 如果主体资料支持，可以在简介中注明“非官方玩家工具”，但名称中不建议使用。
4. 最终服务类目和简介需要与小程序实际功能一致，避免使用“社区”“交易”等未实际提供的表述。
5. 如果名称被占用，可以优先尝试增加“MOD”“创意”“设计”等通用词，而不是增加游戏商标词。
