# 管理员数据筛选与导出

未上线前即可使用管理页和 `adminApi` 导出选中记录，不需要等正式发布。

## 1. 部署管理云函数

在微信开发者工具中右键 `cloudfunctions/adminApi`：

```text
上传并部署：云端安装依赖
```

`adminApi` 不需要 AI Key 或其他额外环境变量。

## 2. 设置初始管理员

1. 用管理员微信进入一次小程序，使 `users` 集合产生用户记录。
2. 在云开发控制台打开 `users` 集合。
3. 复制管理员记录的 `_openid`。
4. 在 `admins` 集合新增记录。

```json
{
  "_openid": "管理员OPENID",
  "role": "SUPER_ADMIN",
  "status": "ACTIVE"
}
```

角色可以设为：

| 角色 | 权限 |
| --- | --- |
| `SUPER_ADMIN` | 查看和导出 |
| `MODERATOR` | 查看和导出 |
| `VIEWER` | 只读，不允许导出 |

不要将管理员 `OPENID` 写入小程序代码。

## 3. 打开管理页

管理员重新进入“我的”页面后，会出现“用户数据管理”入口。

管理页支持：

- 按内容类型筛选
- 按设计状态筛选
- 勾选单条或多条记录
- 按内部用户引用 `ownerRef` 筛选该用户的数据
- 导出已选记录
- 导出当前筛选结果，最多 500 条

导出文件为 JSON，包含提交正文、类型补充、当前状态和最近一次评估结果。

## 4. 导出文件位置

文件由云函数写入：

```text
admin-exports/YYYY-MM-DD/<fileName>.json
```

小程序会先下载文件，然后调用微信文件分享。若当前环境不能分享，管理页会把 `fileID` 复制到剪贴板，可到云开发控制台的云存储中下载。

不要在云存储中配置 `admin-exports/` 的公开读权限。导出文件只应通过管理员会话和管理云函数获取。

## 5. 数据范围与隐私

当前 MVP 只有数据库文本，没有用户图片或音频上传。导出不会返回原始 `_openid`，只保留：

- 内部 `ownerRef`
- 脱敏用户标签

审计记录写入 `admin_audit_logs`，包括操作管理员、动作、记录数量和筛选条件。

生产环境应继续补充：

1. 导出文件自动过期和定期清理
2. 超级管理员操作二次确认
3. 用户数据删除和账号注销
4. 导出失败和异常访问告警
5. 云存储权限与生命周期规则
